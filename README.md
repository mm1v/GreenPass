# GreenPass (Fork by @mm1vs)

**GreenPass** — универсальный модульный прокси-плагин для Android-клиентов Telegram (например, [exteraGram](https://exteragram.app/)), предназначенный для обхода блокировок и проксирования трафика приложения, включая голосовые звонки.

## Что нового в этом форке (v2.5.7f)

* **Полная совместимость с Telegram 12.10.6+:**
  * Поддержка нового расположения класса `org.telegram.utils.proxy.ProxySettings` (с fallback на `org.telegram.proxy.ProxySettings`).
  * Поддержка нового API `ConnectionsManager.setProxySettings(boolean, ProxySettings)` с сохранением обратной совместимости со старой сигнатурой для более ранних версий Telegram.
  * Корректная регистрация через `ProxySettings.toSharedPreferences()` и `SharedConfig.addProxy()`.
* **Бесшовное переключение режимов:**
  * Исправлено динамическое переключение между VLESS, TG WS, AmneziaWG и olcRTC без зависаний и без необходимости перезапускать приложение Telegram.
  * Корректная очистка старых сокетов и своевременное применение нового локального порта в `SharedConfig`.
* **Улучшенная проверка активности прокси:**
  * Проверка фактического статуса включения прокси через SharedPreferences и `SharedConfig.proxyEnabled`.

## Поддерживаемые протоколы и режимы

1. **VLESS / sing-box:** VLESS, VMess, Trojan, Shadowsocks, Hysteria2.
2. **TG WS (Telegram WebSocket):** прямое туннелирование трафика в дата-центры Telegram через WebSocket.
3. **AmneziaWG:** нативный протокол WireGuard с защитой от глубокого анализа пакетов (DPI).
4. **olcRTC:** транспорт WebRTC, маскирующий трафик под аудио/видеоконференции (Яндекс Телемост, Jitsi Meet).
5. **Проксирование звонков:** VoIP-трафик направляется через выделенный Relay-сервер.
6. **Умные правила:** автоотключение при активном системном VPN и списки доверенных Wi-Fi сетей.

## Структура проекта (`src/`)

Исходный код разделен на 10 независимых модулей для удобной разработки и отладки:

* `src/01_foundation.py` — базовые типы, константы и вспомогательные структуры.
* `src/02_i18n.py` — локализация, строковые ресурсы, утилиты состояния прокси Telegram.
* `src/03_protocols.py` — разбор протоколов, парсеры ссылок и конфигураций.
* `src/04_tgws.py` — клиент и обработчик соединений TG WS.
* `src/05_native.py` — проверка сокетов, свободных портов и доступности туннелей.
* `src/06_subscriptions.py` — загрузка, обновление и парсинг подписок.
* `src/07_hooks.py` — хуки интерфейса и перехват системных событий Telegram.
* `src/08_ui.py` — построение пользовательского интерфейса экранов настроек.
* `src/09_modes.py` — управление жизненным циклом режимов (VLESS, AWG, TG WS, olcRTC), создание `ProxyInfo` и вызовы `ConnectionsManager`.
* `src/10_webproxy.py` — веб-прокси адаптер и нативные перехватчики.

## Сборка плагина

Для сборки плагина запустите скрипт:

```bash
python build.py
```

Сборщик:
1. Объединяет файлы из `src/` в правильном порядке.
2. Очищает локальные модульные импорты.
3. Применяет метаданные (версия, автор, иконка).
4. Генерирует готовые файлы `GreenPass.plugin` и `GreenPass.elyx`.
5. Выполняет автоматическую проверку синтаксиса через `py_compile`.
