# GreenPass 3.0.0

## Новые возможности и улучшения
- **Быстрое переключение режима через Pill Stack**:
  - Долгий тап по стопке плашек (Pill Stack / Proxy Pill) или по значку прокси в `DialogsActivity` открывает меню выбора режима подключения плагина прямо из главного экрана чатов.
- **Удобный доступ к звонкам через Relay**:
  - Быстрый переключатель «Звонки через Relay» вынесен на главную страницу настроек плагина для мгновенного включения обхода блокировок голосовых звонков.
  - Детальные параметры Voice Relay и ссылка `tg://relay` доступны в Расширенных настройках.
- **Полный редизайн окна обновлений**:
  - Основная информация о версии плагина и статусе ядра вынесена в верхнюю информационную карточку.
  - Опция автообновления переведена на компактный чекбокс в одну строку вместо громоздких радиокнопок.
  - Кнопка ручной проверки обновлений вынесена в отдельный чистый блок.
- **Очистка интерфейса**:
  - Убрана лишняя техническая приписка `(sing-box)` у VLESS во всех экранах и диалогах.
  - Убран устаревший всплывающий диалог «More and core» при тапе по чипу режима в верхней карточке.
- **Оптимизация и исправление статусов**:
  - Устранен рассинхрон статусов подключения и зависания индикаторов при переключении между протоколами.
  - Исправлены ошибки переподключения и фоновых слушателей.

## ⚠️ Важное предупреждение о блокировках в РФ
- **Блокировка AmneziaWG (AWG) в РФ**:
  - Протокол AmneziaWG (как и классический WireGuard) активно блокируется ТСПУ/РКН на сетях российских операторов (сброс UDP handshake, полная недоступность).
  - Для надежной работы без сбоев рекомендуется использовать режимы **VLESS** (Reality), **TG WS** или **olcRTC**, трафик которых маскируется под легитимный HTTPS/WebSocket/WebRTC.
